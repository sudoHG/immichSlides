# Security policy

This policy covers the immichSlides app and the scripts in this repository.

Report vulnerabilities privately using GitHub's [Report a vulnerability](https://github.com/sudoHG/immichSlides/security/advisories/new) to create a private advisory, or email [by331works@gmail.com](mailto:by331works@gmail.com).

Include the affected version, steps to reproduce, and the potential impact. Do not open public issues for security problems or include real credentials or private photos in your report.
